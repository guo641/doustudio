## 📋 需求来源

用户查看 [license-server-management-guide.md](./license-server-management-guide.md) 后，选择实施第一个"待实现功能"：

> **Web 管理后台**: 浏览器界面查看用户、到期时间、心跳状态，支持一键撤销/延期。适合日常运维，优先级最高。

当前管理方式为 **SSH + SQLite CLI**，每次查询需要手动输入复杂 SQL 语句，操作门槛高。Web 管理后台可提供：
- 可视化用户列表（分页、排序、筛选）
- 统计 Dashboard（总激活数、活跃用户、即将过期等）
- 一键操作（延期、撤销）
- HTTP Basic Auth 保护（用户名/密码存环境变量）

## 🎯 核心功能

### 1. Dashboard 首页
- **路径**: `/admin/`
- **内容**:
  - 4 个统计卡片: 总激活数、24h 活跃、7d 活跃、即将过期 (30d)
  - 快速操作按钮: 查看即将过期用户、查看活跃用户、查看已撤销
- **权限**: 需 HTTP Basic Auth

### 2. 用户列表页
- **路径**: `/admin/licenses`
- **功能**:
  - 表格展示所有激活的 license（分页 50 条/页）
  - 列: HMAC 前缀、首次激活、最后心跳、到期时间、剩余天数、心跳次数、操作
  - 筛选: 全部 / 7d 活跃 / 即将过期 / 已过期
  - 操作: 延期1年、撤销
- **交互**:
  - 点击"延期1年" → 确认弹窗 → POST `/admin/licenses/extend` → 刷新页面
  - 点击"撤销" → 输入原因 → POST `/admin/licenses/revoke` → 刷新页面

### 3. 已撤销列表页
- **路径**: `/admin/revoked`
- **内容**: 表格展示 `revoked_license_hmac_prefixes` 表（HMAC 前缀、撤销时间、撤销原因）

### 4. 认证机制
- **方式**: HTTP Basic Auth
- **凭据**: 环境变量 `DOUSTUDIO_ADMIN_USER` / `DOUSTUDIO_ADMIN_PASSWORD`
- **未配置时**: 放行（开发环境），生产环境必须配置

## 🏗️ 技术栈

- **后端**: FastAPI (已有) + Jinja2 模板 (新增依赖)
- **前端**: Bootstrap 5 (CDN) + 原生 JavaScript
- **数据库**: SQLite (已有 schema，无需修改)
- **部署**: 腾讯云 CVM Ubuntu 24.04, systemd service

**选型理由**:
- ✅ 与现有项目一致（FastAPI）
- ✅ 服务端渲染，无需前后端分离构建
- ✅ 可复用现有 `db.py` / `storage` 模块
- ✅ 部署简单（只需追加路由，无需单独服务）

## 🔐 安全考量

### 1. 认证强度
- ✅ HTTP Basic Auth (简单但足够，配合 HTTPS 安全)
- ✅ 密码存环境变量（不入代码库）
- ✅ `secrets.compare_digest()` 防时序攻击
- ⚠️ 单用户模式（未来可扩展为多用户 + JWT）

### 2. 权限隔离
- ✅ 所有 `/admin/*` 路径需认证
- ✅ heartbeat API (`/api/heartbeat`) 无认证（客户端公开）
- ✅ healthz (`/healthz`) 无认证（监控探针）

### 3. 撤销操作
- ✅ 直接用 `license_hmac` 计算 prefix（无需 license_token + fingerprint）
- ✅ `INSERT OR IGNORE` 防重复撤销
- ⚠️ 无审计日志（v0.3.11 可实现 `admin_audit_log` 表）

### 4. 延期操作
- ✅ 直接修改 `expires_at` 字段（`COALESCE(expires_at, now) + days*86400`）
- ✅ 永久授权 (`expires_at=NULL`) 延期后变为有期限（预期行为）
- ⚠️ 无审计日志

### 5. HTTPS
- ✅ 与 heartbeat API 共用 8443 端口，自签证书 + SPKI pin
- ✅ 浏览器访问时会提示"不安全"（因为自签证书），需点击"继续访问"

## 📝 后续改进方向（v0.3.11+）

### 1. 审计日志表
```sql
CREATE TABLE admin_audit_log (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp INTEGER NOT NULL,
    operator TEXT NOT NULL,  -- 操作人（admin 用户名）
    action TEXT NOT NULL,     -- "revoke" | "extend"
    target_hmac TEXT NOT NULL,
    details TEXT              -- JSON: {"reason": "...", "days": 365, ...}
```

### 2. 多用户 + JWT 认证
- 用户表 (`admin_users`) 存储用户名 + bcrypt 密码哈希
- 登录页签发 JWT token → 存 cookie
- 更细粒度权限（只读用户 vs 管理员）

### 3. 批量操作
- 勾选多条 license → 批量延期 / 批量撤销
- 前端用 checkbox + "批量操作"按钮

### 4. 导出功能
- 导出 CSV/Excel（用户列表 + 统计报表）
- 用于财务对账或外部报表

### 5. 图表可视化
- Chart.js 或 ECharts 绘制心跳频率分布柱状图
- 用户增长趋势折线图（按天/周/月）

### 6. WebSocket 实时监控
- 服务端推送最新心跳事件到 Dashboard
- 实时更新活跃用户数

### 7. 自动到期提醒
- 定时任务（systemd timer 或 cron）查询即将过期用户

### 8. PostgreSQL 迁移
