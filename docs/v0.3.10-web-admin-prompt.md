**目标**: 为 License Server 增加 Web 管理界面，支持查看用户、到期时间、心跳状态、一键撤销/延期

## 🎯 需求概述

### 核心功能

1. **用户列表页**
   - 表格展示所有激活的 license
   - 列: HMAC 前缀、首次激活、最后心跳、到期时间、剩余天数、心跳次数、操作
   - 支持排序（按到期时间、最后心跳）
   - 支持筛选（即将过期、已过期、活跃用户）
   - 分页（每页 50 条）

2. **撤销功能**
   - 单条撤销: 点击"撤销"按钮 → 输入原因 → 确认
   - 批量撤销: 勾选多条 → 批量撤销
   - 撤销后显示在"已撤销"tab

3. **延期功能**
   - 单条延期: 点击"延期"按钮 → 选择延长时间（30天/90天/1年/自定义）→ 确认
   - 批量延期: 勾选多条 → 批量延期

4. **统计 Dashboard**
   - 总激活数、24h 活跃、7d 活跃、已撤销数
   - 即将过期（30 天内）用户数
   - 心跳频率分布图（echarts 或 Chart.js）

5. **已撤销列表页**
   - 表格展示 `revoked_license_hmac_prefixes` 表
   - 列: HMAC 前缀、撤销时间、撤销原因

6. **认证保护**
   - 简单 HTTP Basic Auth（用户名/密码存环境变量）
   - 或 JWT token（更安全）

---

## 🏗️ 技术栈建议

### 后端

**选项 A: FastAPI + Jinja2 模板（推荐，与现有项目一致）**
- ✅ 已有 FastAPI 依赖
- ✅ 服务端渲染，无需前后端分离
- ✅ 可复用现有 `db.py` / `kms_adapter.py`

**选项 B: FastAPI + Vue/React SPA**
- ✅ 更现代的交互体验
- ❌ 需要额外前端构建流程
- ❌ CORS 配置

### 前端（如果用 Jinja2 模板）

- **CSS 框架**: Tailwind CSS（通过 CDN）或 Bootstrap 5
- **图表**: Chart.js（CDN）或 ECharts
- **表格**: 原生 HTML table + 少量 JS（排序/筛选客户端实现）

### 认证

- **HTTP Basic Auth**（最简单）: 
  - 环境变量 `DOUSTUDIO_ADMIN_USER` / `DOUSTUDIO_ADMIN_PASSWORD`
  - FastAPI `HTTPBasic` 依赖
- **JWT Token**（更安全）: 
  - 登录页 → 签发 token → 存 cookie
  - 需要额外的 session 管理

"""管理后台查询辅助函数。"""
from __future__ import annotations

import sqlite3
from typing import Any

from .db import db_connection


def get_all_licenses(
    *,
    page: int = 1,
    per_page: int = 50,
    order_by: str = "last_seen_at",
    order: str = "DESC",
    filter_status: str | None = None,  # "expiring_30d" | "expired" | "active_7d"
) -> tuple[list[dict[str, Any]], int]:
    """获取所有 license，支持分页、排序、筛选。
    
    Returns:
        (licenses, total_count)
    """
    offset = (page - 1) * per_page
    
    # 基础查询
    where_clauses = []
    params: list[Any] = []
    
    if filter_status == "expiring_30d":
        where_clauses.append(
            "expires_at IS NOT NULL AND expires_at > strftime('%s', 'now') "
            "AND (expires_at - strftime('%s', 'now')) < 2592000"
        )
    elif filter_status == "expired":
        where_clauses.append("expires_at IS NOT NULL AND expires_at < strftime('%s', 'now')")
    elif filter_status == "active_7d":
        where_clauses.append("(strftime('%s', 'now') - last_seen_at) < 604800")
    
    where_sql = f"WHERE {' AND '.join(where_clauses)}" if where_clauses else ""
    
    # 允许的排序字段
    allowed_order_by = {"last_seen_at", "first_seen_at", "expires_at", "heartbeat_count"}
    if order_by not in allowed_order_by:
        order_by = "last_seen_at"
    if order not in ("ASC", "DESC"):
        order = "DESC"
    
    with db_connection() as conn:
        # 总数
        count_row = conn.execute(
            f"SELECT COUNT(*) as cnt FROM license_activations {where_sql}"
        ).fetchone()
        total_count = count_row["cnt"] if count_row else 0
        
        # 分页数据
        rows = conn.execute(
            f"""
            SELECT 
                license_hmac,
                fingerprint_hex,
                expires_at,
                first_seen_at,
                last_seen_at,
                heartbeat_count
            FROM license_activations
            {where_sql}
            ORDER BY {order_by} {order}
            LIMIT ? OFFSET ?
            """,
            (per_page, offset),
        ).fetchall()
        
        licenses = [dict(row) for row in rows]
    
    return licenses, total_count


def get_statistics() -> dict[str, int]:
    """获取统计数据。"""
    with db_connection() as conn:
        row = conn.execute("""
            SELECT 
                COUNT(*) as total,
                SUM(CASE WHEN (strftime('%s', 'now') - last_seen_at) < 86400 THEN 1 ELSE 0 END) as active_24h,
                SUM(CASE WHEN (strftime('%s', 'now') - last_seen_at) < 604800 THEN 1 ELSE 0 END) as active_7d,
                SUM(CASE WHEN expires_at IS NOT NULL AND expires_at > strftime('%s', 'now') 
                         AND (expires_at - strftime('%s', 'now')) < 2592000 THEN 1 ELSE 0 END) as expiring_30d
            FROM license_activations
        """).fetchone()
        
        revoked_row = conn.execute("SELECT COUNT(*) as cnt FROM revoked_license_hmac_prefixes").fetchone()
        
        return {
            "total": row["total"] if row else 0,
            "active_24h": row["active_24h"] if row else 0,
            "active_7d": row["active_7d"] if row else 0,
            "expiring_30d": row["expiring_30d"] if row else 0,
            "revoked": revoked_row["cnt"] if revoked_row else 0,
        }


def extend_license_expiry(license_hmac: str, days: int) -> bool:
    """延长某个 license 的到期时间。
    
    Args:
        license_hmac: license HMAC
        days: 延长天数（正数）
    
    Returns:
        True if updated, False if not found
    """
    with db_connection() as conn:
        cursor = conn.execute(
            """
            UPDATE license_activations
            SET expires_at = COALESCE(expires_at, strftime('%s', 'now')) + ?
            WHERE license_hmac = ?
            """,
            (days * 86400, license_hmac),
        )
        return cursor.rowcount > 0


def get_revoked_licenses() -> list[dict[str, Any]]:
    """获取所有已撤销的 license。"""
    with db_connection() as conn:
        rows = conn.execute("""
            SELECT prefix, revoked_at, reason
            FROM revoked_license_hmac_prefixes
            ORDER BY revoked_at DESC
        """).fetchall()
        return [dict(row) for row in rows]
```

"""HTTP Basic Auth 认证。"""
from __future__ import annotations

import os
import secrets
from typing import Annotated

from fastapi import Depends, HTTPException, status
from fastapi.security import HTTPBasic, HTTPBasicCredentials

security = HTTPBasic()

ADMIN_USER = os.environ.get("DOUSTUDIO_ADMIN_USER", "admin")
ADMIN_PASSWORD = os.environ.get("DOUSTUDIO_ADMIN_PASSWORD", "")

if not ADMIN_PASSWORD:
    import logging
    logger = logging.getLogger(__name__)
    logger.warning("DOUSTUDIO_ADMIN_PASSWORD 未配置,Web 管理后台无密码保护!")


def verify_credentials(
    credentials: Annotated[HTTPBasicCredentials, Depends(security)]
) -> str:
    """验证 HTTP Basic Auth 凭据。
    
    Returns:
        username (str)
    
    Raises:
        HTTPException 401 if invalid
    """
    if not ADMIN_PASSWORD:
        # 未配置密码 → 放行（开发环境）
        return credentials.username
    
    correct_username = secrets.compare_digest(credentials.username.encode(), ADMIN_USER.encode())
    correct_password = secrets.compare_digest(credentials.password.encode(), ADMIN_PASSWORD.encode())
    
    if not (correct_username and correct_password):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Incorrect username or password",
            headers={"WWW-Authenticate": "Basic"},
        )
    
    return credentials.username
```

```python
"""Web 管理后台路由。"""
from __future__ import annotations

import time
from typing import Annotated

from fastapi import APIRouter, Depends, Form, Request
from fastapi.responses import HTMLResponse, RedirectResponse
from fastapi.templating import Jinja2Templates

from ..config import REVOKED_PREFIX_LEN
from ..storage.admin_queries import (
    extend_license_expiry,
    get_all_licenses,
    get_revoked_licenses,
    get_statistics,
)
from ..storage.db import db_connection
from .auth import verify_credentials

router = APIRouter(prefix="/admin", tags=["admin"])
templates = Jinja2Templates(directory="server/app/web/templates")


@router.get("/", response_class=HTMLResponse)
def dashboard(
    request: Request,
    username: Annotated[str, Depends(verify_credentials)],
):
    """Dashboard 首页。"""
    stats = get_statistics()
    return templates.TemplateResponse(
        "dashboard.html",
        {"request": request, "stats": stats, "username": username},
    )


@router.get("/licenses", response_class=HTMLResponse)
def licenses_page(
    request: Request,
    username: Annotated[str, Depends(verify_credentials)],
    page: int = 1,
    filter: str | None = None,
):
    """用户列表页。"""
    licenses, total = get_all_licenses(
        page=page,
        per_page=50,
        filter_status=filter,
    )
    
    # 计算剩余天数
    now = int(time.time())
    for lic in licenses:
        if lic["expires_at"]:
            lic["days_left"] = (lic["expires_at"] - now) // 86400
        else:
            lic["days_left"] = None  # 永久授权
    
    total_pages = (total + 49) // 50
    
    return templates.TemplateResponse(
        "licenses.html",
        {
            "request": request,
            "licenses": licenses,
            "page": page,
            "total_pages": total_pages,
            "total": total,
            "filter": filter,
            "username": username,
        },
    )


@router.post("/licenses/extend")
def extend_license(
    username: Annotated[str, Depends(verify_credentials)],
    license_hmac: Annotated[str, Form()],
    days: Annotated[int, Form()],
):
    """延期 license。"""
    success = extend_license_expiry(license_hmac, days)
    if not success:
        return {"ok": False, "error": "License not found"}
    return {"ok": True}


@router.post("/licenses/revoke")
def revoke_license(
    username: Annotated[str, Depends(verify_credentials)],
    license_hmac: Annotated[str, Form()],
    reason: Annotated[str, Form()] = "",
):
    """撤销 license（加入黑名单）。
    
    注意: 这里直接操作 revoked_license_hmac_prefixes 表,
    不需要 license_token 和 fingerprint（因为我们已经有 hmac）。
    """
    prefix = license_hmac[:REVOKED_PREFIX_LEN]
    
    with db_connection() as conn:
        conn.execute(
            "INSERT OR IGNORE INTO revoked_license_hmac_prefixes (prefix, revoked_at, reason) VALUES (?, ?, ?)",
            (prefix, int(time.time()), reason),
        )
    
    return {"ok": True}


@router.get("/revoked", response_class=HTMLResponse)
def revoked_page(
    request: Request,
    username: Annotated[str, Depends(verify_credentials)],
):
    """已撤销列表页。"""
    revoked = get_revoked_licenses()
    return templates.TemplateResponse(
        "revoked.html",
        {"request": request, "revoked": revoked, "username": username},
    )
```

import datetime

def timestamp_to_datetime(ts: int | None) -> str:
    if ts is None:
        return "-"
    return datetime.datetime.fromtimestamp(ts, tz=datetime.timezone.utc).strftime("%Y-%m-%d %H:%M:%S UTC")

web_routes.templates.env.filters["timestamp_to_datetime"] = timestamp_to_datetime

**对应的 API 端点**（`app/web/routes.py`）:
```python
@router.get("/api/heartbeat-distribution")
def heartbeat_distribution(
    username: Annotated[str, Depends(verify_credentials)],
):
    """心跳频率分布（用于图表）。"""
    with db_connection() as conn:
        rows = conn.execute("""
            SELECT 
                CASE 
                    WHEN (strftime('%s', 'now') - last_seen_at) < 3600 THEN '< 1 hour'
                    WHEN (strftime('%s', 'now') - last_seen_at) < 86400 THEN '< 1 day'
                    WHEN (strftime('%s', 'now') - last_seen_at) < 604800 THEN '< 7 days'
                    WHEN (strftime('%s', 'now') - last_seen_at) < 2592000 THEN '< 30 days'
                    ELSE '> 30 days'
                END as bucket,
                COUNT(*) as cnt
            FROM license_activations
            GROUP BY bucket
            ORDER BY MIN(strftime('%s', 'now') - last_seen_at)
        """).fetchall()
        
        labels = [row["bucket"] for row in rows]
        counts = [row["cnt"] for row in rows]
        
        return {"labels": labels, "counts": counts}
```

## 🔍 常见问题排查

### 1. 访问 `/admin/` 返回 404

**原因**: 路由未正确挂载

**排查**:
```bash
sudo journalctl -u doustudio-license.service -n 100 | grep -i "error\|exception"
```

**解决**: 检查 `app/main.py` 是否正确 `include_router(web_routes.router)`

### 2. 浏览器显示 "Internal Server Error"

**原因**: Jinja2 模板路径错误或过滤器未注册

**排查**:
```bash
sudo journalctl -u doustudio-license.service -f
# 然后刷新浏览器，观察日志
```

**解决**: 确认 `templates` 目录在 `server/app/web/templates/`，且 `timestamp_to_datetime` 过滤器已注册

### 3. 延期/撤销操作无响应

**原因**: POST 请求返回错误或 JavaScript 报错

**排查**: 浏览器 DevTools → Console / Network tab

**解决**: 检查 `/admin/licenses/extend` 和 `/admin/licenses/revoke` 端点返回的 JSON

### 4. 数据库权限错误

**原因**: SQLite 文件权限不正确

**排查**:
```bash
ls -l /var/lib/doustudio/license.sqlite3
# 应该是 doustudio:doustudio 权限
```

**解决**:
```bash
sudo chown doustudio:doustudio /var/lib/doustudio/license.sqlite3
```
