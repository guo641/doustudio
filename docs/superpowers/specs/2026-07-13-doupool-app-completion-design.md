# DouPool 功能补全设计

## 目标与范围

补全当前侧边栏中尚未实现的账号管理、生成结果、运行日志和设置功能，同时统一导航图标和页面布局。视频任务继续作为核心工作流，并新增每日额度持久化、限额冷却和自动换号。

本次不新增图片生成业务。用户要求删除的是账号页统计卡片和每页主体顶部的大标题/说明区域；顶部紧凑面包屑栏继续保留。

## 导航与公共布局

- 安装并使用 `lucide-vue-next`，图标随前端依赖下载到本地，不依赖运行时外部 CDN。
- 侧边栏使用 `UsersRound`、`Clapperboard`、`Download`、`ScrollText`、`Settings` 图标。
- 所有导航项可点击，并由统一页面枚举控制激活状态。
- 删除账号页和视频任务页的 `.title` 主标题区域。
- 删除账号页三张统计卡片。
- 各页面内容从顶部紧凑栏下方直接开始，保留一致的内边距。

## 账号池

账号池继续使用表格，增加以下能力：

- 显示登录状态、今日额度、限额恢复时间和是否参与调度。
- 启用/停用账号，调用现有账号更新 API。
- 删除账号前二次确认，删除后同步清理本地浏览器会话。
- 对失效账号提供重新登录入口。
- 今日额度格式为“已用/总量”；服务端已返回限额时显示“今日额度已用完”。

## 视频任务与额度调度

- 沿用已完成的视频任务表格、筛选、详情展开和失败重试。
- 新任务始终先进入队列；调度器在后台分配账号。
- 账号每日额度默认 5 点，可在设置中修改。
- 每次豆包接受一个视频生成任务后，本地使用量增加 1。
- 若豆包返回 `rate limited`，以服务端结果为准：该账号当日额度立即视为耗尽，冷却至次日额度重置时间，并自动尝试下一个账号。
- 所有账号不可用时，任务保持 `queued`，错误说明显示“等待可用账号”，不直接失败。
- 额度按 Asia/Shanghai 的业务日期重置；应用启动和每次调度前都检查是否跨过重置时间。
- 同一账号同时只运行一个视频生成任务；全局并发数由设置控制。

## 生成结果

- 使用独立表格展示成功任务，不重复显示未完成任务。
- 列包含：任务描述、模型参数、执行账号、完成时间、结果和操作。
- 结果操作包含网页预览、无水印下载和复制链接。
- 下载目录来自设置；桌面壳提供打开下载目录能力时显示“打开目录”，否则隐藏。
- 不使用封面卡片或瀑布流，保持表格扫描效率。

## 运行日志

- 日志页使用表格展示时间、级别、模块、事件和消息。
- 支持关键词搜索、日志级别筛选和自动刷新。
- 提供“清空日志”按钮并进行确认。
- API 支持分页上限和清空；日志消息作为纯文本渲染。
- 错误日志可展开查看完整内容，但不在界面展示 Cookie、Token 或完整请求签名。

## 设置

设置使用分组表单，并持久化到 SQLite：

### 调度

- 全局并发数，默认 1，允许 1–10。
- 每账号每日额度，默认 5，允许 1–100。
- 额度重置时间，默认 `00:00`。
- 调度策略：最少使用优先或轮询，默认最少使用优先。

### 视频默认值

- 默认模型：Seedance 2.0、Fast 或 Mini。
- 默认时长：5 秒或 10 秒。
- 默认比例：现有六种比例之一。

### 文件与日志

- 视频下载目录。
- 日志级别：DEBUG、INFO、WARNING、ERROR。
- 日志保留天数，默认 30，允许 1–365。
- 显示只读数据目录路径。
- “备份数据库”将 SQLite 一致性快照写入数据目录下的 `backups/`，文件名包含时间戳。

设置保存后立即更新前端默认参数；调度和日志设置在后端安全地应用，不要求重启应用。

## 数据模型与迁移

数据库增加以下内容：

- `AppSetting`：键、JSON 值、更新时间。
- `Account.video_quota_used`：当日已使用点数。
- `Account.video_quota_date`：额度所属业务日期。
- `Account.video_limited_until`：服务端限额冷却结束时间。
- `VideoTask.account` 改为可空，使任务能在未分配账号时持久化排队。

迁移必须保留现有账号、登录会话、任务、结果和日志。SQLite 外键在表重建迁移期间显式处理，并通过旧版本数据库测试验证。

## API

- `GET /api/settings`：返回完整设置和只读路径信息。
- `PUT /api/settings`：验证并保存允许修改的设置。
- `POST /api/settings/backup`：创建数据库快照并返回文件路径。
- `DELETE /api/logs`：清空日志。
- `PATCH /api/accounts/{id}`：继续处理启用状态。
- `DELETE /api/accounts/{id}`：继续删除账号和会话。
- 账号和任务响应补充额度、冷却和未分配账号兼容字段。

所有 API 继续使用本地令牌鉴权。路径设置只接受本机绝对路径，并在保存前创建或验证目录。

## 错误处理

- `rate limited` 转换为专用错误类型，调度器据此冷却账号并换号，不依赖错误字符串散落判断。
- 数据库备份失败、目录不可写和设置验证失败返回可读中文错误。
- 自动刷新失败保留当前列表并显示 Toast，不清空已有数据。
- 删除账号时若存在运行任务则拒绝删除，并说明原因。
- 应用关闭时取消运行线程并保留排队任务；下次启动恢复排队。

## 实施拆分

1. 公共导航、Lucide 图标和紧凑布局。
2. 设置模型、API、设置页和数据库备份。
3. 额度字段、队列迁移、限额冷却与自动换号调度。
4. 账号池管理操作和额度展示。
5. 生成结果页。
6. 运行日志页。
7. 启动恢复、综合测试和生产构建。

每个子项目都采用测试先行，并在完成后保持应用可运行。

## 验收标准

- 左侧导航全部使用本地打包的 Lucide SVG 图标且可以切换页面。
- 主体大标题、说明文字和账号统计卡片全部移除。
- 账号启停、删除、重登入口和额度状态可用。
- 限额账号自动冷却到次日并切换其他账号；无账号时任务留在队列。
- 生成结果页可以预览、复制和下载无水印视频。
- 日志页可以筛选、刷新和清空日志。
- 设置保存、读取、即时生效和数据库备份可用。
- 旧数据库迁移后数据不丢失。
- Python 测试、Vue 测试、TypeScript 检查和 Vite 生产构建全部通过。
