# 视频任务表格设计

## 目标

将当前卡片式视频任务列表改为暗色 Linear 风格的数据表格，使多账号、多任务场景下的状态、参数、账号、额度和结果更容易扫描与管理。

## 表格结构

表格固定包含以下列：

1. 状态：排队中、分配账号、生成中、获取无水印、已完成、失败、已取消。
2. 任务描述：显示提示词摘要，单行溢出省略；点击后展开完整提示词。
3. 模型参数：合并显示模型、时长和画面比例。
4. 执行账号：显示实际被后台调度的账号；未分配时显示“等待分配”。
5. 额度：显示该账号当日已使用点数和每日总额度，格式为“已用/5”；数据未知时显示“—”。
6. 创建时间：以本地时区显示月日和时分。
7. 结果：成功任务提供“预览”和“无水印下载”，其他状态显示“—”。
8. 操作：运行中任务可取消，失败任务可重新加入队列，其余操作收纳在省略菜单中。

## 交互

- 表格上方提供关键词搜索、状态筛选和账号筛选。
- 提示词单元格可展开；失败任务展开后同时显示完整错误信息。
- 任务状态使用低饱和度彩色标签，运行中状态显示当前阶段。
- 表头保持清晰，窄窗口允许横向滚动，避免挤压关键内容。
- 空列表继续使用现有空状态，并保留“添加任务”入口。
- 重新加入队列复用原任务的提示词和模型参数，创建一条新任务，不覆盖历史记录。

## 数据与接口

- 列表继续由 `GET /api/video-tasks` 提供。
- 前端任务类型补充账号额度字段；额度功能尚未落地时按未知值兼容显示。
- 重试通过 `POST /api/video-tasks` 创建新任务。
- 取消操作只有在后端取消接口可用时启用；在接口完成前不展示无效按钮。
- 无水印下载优先使用 `result_url`，备用链接保留在任务数据中，不直接占用表格列。

## 视觉规范

- 使用现有暗色背景、细边框和紧凑行高。
- 表头字体较小、颜色弱化；正文保持足够对比度。
- 行悬停时仅轻微提亮背景，不使用大面积阴影。
- 提示词列获得最多可用宽度，状态、时间和操作列保持稳定宽度。

## 错误与边界情况

- 缺少账号时显示“等待分配”。
- 缺少额度数据时显示“—”，不推测剩余额度。
- 下载链接缺失时不展示下载操作。
- 错误文本经过普通文本渲染，不插入 HTML。
- 长提示词、长账号名和大量任务不会破坏表格布局。

## 验收标准

- 视频任务页不再显示任务卡片，而是显示上述八列表格。
- 搜索、状态筛选和账号筛选可组合使用。
- 长提示词可展开和收起。
- 失败行可查看错误并通过原参数创建新任务。
- 成功行可打开预览并下载无水印视频。
- 移动或窄窗口下表格可横向滚动。
- 前端组件测试覆盖弹窗创建任务、表格渲染、筛选和失败重试。
- TypeScript 检查、前端测试和生产构建通过。
